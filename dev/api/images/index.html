Images

An image is an array whose grid dimensions lie on a grid geometry, with a named description of every dimension.

TomoImages.AbstractTomoImage — Type
AbstractTomoImage{T,N}

Supertype of arrays that know where their voxels are. An image implements the AbstractArray interface and the accessors parent, geometry, TomoImages.dims and meta; functions of this package use only these, never the fields of an image type.

source
TomoImages.TomoImage — Type
TomoImage(data, geom; dims=(x1=GridAxis(1), ..., dim_d=1:n, ...), meta=(;))

A tomographic image: an array data whose grid dimensions lie on the geometry geom, with a named description of every dimension.

  • dims: a NamedTuple with one entry per dimension of data, in order. A GridAxis(k) marks index axis k of the geometry; every grid axis appears once. Any other dimension is described by a vector with one value per index: a NumericAxis (ordered coordinates with a unit), a CategoricalAxis (labels), or any AbstractVector. The names are part of the type. Default: the grid axes x1, x2, ... first, then dim_d = 1:n for further dimensions.
  • meta: free metadata; geometry code never reads it.

Indexing and view with integers, ranges and colons (also by name, img[time=3]), permutedims, reverse and broadcasting keep the geometry, the dimensions and the metadata wherever the result still has grid dimensions; other indices (vectors, logical masks) give a plain array. Broadcasting several images requires them in one space and on the same grid. parent(img) is the array, on whatever device it lives.

Throws an ArgumentError or a DimensionMismatch if dims does not fit the data and the geometry.

Example

g = GridGeometry((40, 40, 20); spacing=(1.0, 1.0, 2.0))
img = TomoImage(rand(Float32, 2, 40, 40, 20, 100), g;
                   dims=(contrast=CategoricalAxis(["tracer A", "tracer B"]),
                         x=GridAxis(1), y=GridAxis(2), z=GridAxis(3),
                         time=NumericAxis(range(0, step=0.02, length=100); unit="s")))
img[contrast=2, time=51]                    # by index: a 40x40x20 TomoImage on g
selectvalue(img; contrast="tracer B", time=1.0)   # the same, by value

TomoImages.dims — Function
dims(img)

The description of every dimension of img, in order, as a NamedTuple: a GridAxis for the grid dimensions and a vector of values for the others. Public, not exported: DimensionalData.jl exports a function of the same name.

source
TomoImages.griddims — Function
griddims(img)

The array dimensions of the index axes 1, 2, ... of the geometry of img: griddims(img)[k] is the dimension marked GridAxis(k).

source

meta(img)

The metadata of img.

TomoImages.selectvalue — Function
selectvalue(img; name=value, ...)

The part of img at the given values of its named non-grid dimensions: the nearest coordinate on a numeric axis, the equal label on a CategoricalAxis (see TomoImages.indexof). Each selected dimension is dropped. Indexing with integers and ranges, img[time=3], always means indices.

Example

selectvalue(img; contrast="tracer B", time=1.5)

Axes

Every dimension of an image is a grid axis or is described by a vector of values.

TomoImages.GridAxis — Type
GridAxis(k)

Marks an array dimension as index axis k of the image's geometry. Grid axes carry no coordinates of their own: the geometry places all of them together, since its direction may mix them. The name of the dimension (the key in dims) only labels the index axis; it does not say that the axis runs along an axis of the space.

source
TomoImages.NumericAxis — Type
NumericAxis(values; unit=nothing)

An ordered axis with a coordinate for every index, in its own unit: time in s, echo time in ms, frequency in kHz. It is an AbstractVector of its coordinates, which should be sorted (selection by value assumes it; it is not checked). unit is any value that describes them (a string, or a unit of Unitful.jl).

Any AbstractVector can describe a non-grid dimension; NumericAxis adds the unit.

source
TomoImages.CategoricalAxis — Type
CategoricalAxis(labels)

An unordered axis of labels without distances between them: contrasts or tracers, coils. It is an AbstractVector of its labels. Labels are found by equality, also when they are numbers (coil 3).

source
TomoImages.unit — Function
unit(axis)

The unit of the coordinates of a NumericAxis; nothing for other axes.

source
TomoImages.indexof — Function
indexof(axis, value)

The index of value on the axis. On a numeric axis (a vector of numbers that is not a CategoricalAxis) the index of the nearest coordinate, which must lie within half the distance to its neighbor at the ends (on an axis of one coordinate, the value must be equal); on other axes the index of the first equal element. Throws an ArgumentError if there is none.
