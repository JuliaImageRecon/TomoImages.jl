Resampling

resample puts an image onto another grid, in the same space or through a transform. The resampler is its first argument.

TomoImages.resample — Function
resample([r,] img, target[, t]; fillvalue=zero(resample_eltype(r, eltype(img))))

The image img on the geometry target: every output voxel takes the value of img at its position, interpolated by the resampler r (default: TomoImages.default_resampler(img)).

  • target: a GridGeometry with as many index and world dimensions as the geometry of img.
  • t: without a transform, target and the geometry of img must be in the same space. With an AffineTransform, positions are mapped from the space of target to the space of img: source(t) must be the space of target (the fixed image) and target(t) that of img (the moving image). This is the direction registration results are stored in; the output is pulled from the input, so every output voxel gets exactly one value.
  • fillvalue: the value of output voxels whose position lies outside the voxels of img (farther than half a voxel beyond its outermost voxel centers).

The other dimensions are resampled one by one with the same positions; the description of the dimensions and the metadata are kept. Throws an ArgumentError if the spaces, the number of dimensions or the resampler (see TomoImages.supports) do not fit.

Example

g = GridGeometry((64, 64); spacing=(1.0, 1.0), origin=(-31.5, -31.5))
img = TomoImage(rand(Float32, 64, 64), g)
fine = GridGeometry((128, 128); spacing=(0.5, 0.5), origin=(-31.75, -31.75))
resample(img, fine)                          # on a twice finer grid, linear interpolation
resample(NearestResampler(), img, fine; fillvalue=NaN32)

TomoImages.NearestResampler — Type
NearestResampler()

The value of the input voxel nearest to each output position. A position exactly halfway between two voxel centers takes the voxel with the even index (Julia's round). The default for integer and Bool images such as label maps and masks, whose values must not be averaged.

source
TomoImages.LinearResampler — Type
LinearResampler()

Multilinear interpolation between the 2^N input voxels around each output position (bilinear in 2D, trilinear in 3D). Exact at voxel centers, and for images that are linear in the index at positions between the outermost voxel centers; in the outer half voxel the value of the edge voxel is taken. The default for images that are not integer or Bool.

source
TomoImages.BSplineResampler — Type
BSplineResampler(degree)

B-spline interpolation of degree 0 to 3 with Interpolations.jl, through the voxel values (an interpolating spline; degree 2 and 3 prefilter the input, with linear extrapolation as the boundary condition). Runs on the CPU, for images whose data is an Array (not a view or a GPU array). Throws an ArgumentError for other degrees.

source
TomoImages.default_resampler — Function
default_resampler(img)

The resampler resample uses without one: NearestResampler for integer and Bool images, LinearResampler otherwise. It depends only on the element type; loading a package never changes it.

Implementing a resampler

A resampler is a type of its own with a method of TomoImages.resample!; Write a Resampler shows one.

TomoImages.AbstractResampler — Type
AbstractResampler

Supertype of resamplers: how resample interpolates the input at the positions of the output voxels. A resampler implements

resample!(r, out, img, map; fillvalue)

(see TomoImages.resample!). It may implement TomoImages.supports to refuse inputs before the call, and TomoImages.resample_eltype if its output has another element type than the default. The resampler is the first argument, and its type belongs to the package that implements it, so that packages add resamplers without defining methods for types of others.

All resamplers of this package read the input over the extent of its voxels: a position up to half a voxel beyond the outermost voxel centers takes the value at the edge; positions farther out get fillvalue.

source
TomoImages.resample! — Function
resample!(r, out, img, map; fillvalue)

Writes into the array out the values of the image img, interpolated by the resampler r. The method a custom AbstractResampler implements; resample allocates out, computes map and calls it.

  • out has the size of the output and lives on the device of img; its grid dimensions have the size of the target grid, all other dimensions that of img.
  • For every output index, its indices in the grid dimensions, ordered as the index axes of the geometry (griddims(img)[k] is the array dimension of index axis k), form j; map(j) (an TomoImages.IndexMap) is the continuous index of the same position in the grid of img, in the same order. The indices in all other dimensions are the same in out and img.
  • Positions outside the input get fillvalue, which resample always passes, converted to the element type of out.
source
TomoImages.supports — Function
supports(r, img)

Whether the resampler r can resample img; resample throws an ArgumentError otherwise. Defaults to true.

source
TomoImages.resample_eltype — Function
resample_eltype(r, T)

The element type of the output of the resampler r for input elements of type T. Interpolation averages, so by default integers and Bool become Float32 and other types stay; NearestResampler keeps every type. A resampler that returns another type implements a method.

source
TomoImages.IndexMap — Type
IndexMap{N,T}

The affine map from a voxel index j of the output grid to the continuous voxel index i = M * j + c of the input grid at the same position (after the transform, if any). isbits, so that kernels take it as an argument; m(j) evaluates it.

source
TomoImages.index_map — Function
index_map(out, in[, t]; eltype=Float64)

The IndexMap from the voxels of the geometry out to the continuous voxel indices of the geometry in: the position of output voxel j in the space of out, mapped by t into the space of in (without t, positions are taken as they are), as an index of in. Both geometries need the same numbers of index and world dimensions. The map is computed in Float64 and stored in eltype. It does not check spaces; resample does before it calls index_map.
