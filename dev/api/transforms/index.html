Transforms

Transforms map positions from one space to another and carry both spaces, so that composition and resampling check them.

TomoImages.AbstractSpatialTransform — Type
AbstractSpatialTransform

Supertype of transforms: maps from positions in one space (its source) to positions in another (its target). A transform implements source(t), target(t) and t(x) for a point x, and inv(t) where it has an inverse. The functions of this package that take transforms (resample, TomoImages.compose, transform_geometry) accept AffineTransforms.

Registration results are stored in the direction resampling evaluates: from the space of the fixed image (the output grid) to the space of the moving image (the image that is resampled). See resample.

source
TomoImages.AffineTransform — Type
AffineTransform(A, b; source, target)

The transform x -> A * x + b from positions in the space source to positions in the space target. The spaces are part of the type, so that TomoImages.compose and resample can check them; with isbits spaces the transform is isbits. inv(t) is the transform from target back to source.

Example

# a rotation by 90 degrees about z and a shift of 120 mm along z, from LPS into the space of a scanner
t = AffineTransform([0 -1 0; 1 0 0; 0 0 1], [0, 0, 120]; source=LPS(), target=MPIScanner())
t([1.0, 0.0, 0.0])                          # [0, 1, 120]

TomoImages.compose — Function
compose(t2, t1)

t2 ∘ t1

The transform that applies t1 and then t2: from source(t1) to target(t2). Requires target(t1) == source(t2).

TomoImages.transform_between — Function
transform_between(from, to)

The transform between two spaces whose relation is fixed by convention: LPS to RAS and back. Packages add methods for their own spaces, with acquisition metadata as an extra argument where the relation depends on it: transform_between(from, to, meta).

source
TomoImages.transform_geometry — Function
transform_geometry(g, t)

The geometry of the same voxels as g, written in the space target(t): the origin is mapped by t and the direction by its linear part, which must be orthogonal (a rotation or a reflection). The voxels do not move; only the coordinates they are described in change. The result has the element type of the transform. Throws an ArgumentError if the spaces do not fit or the linear part is not orthogonal (to within 64 * eps(Float32)).
